01 切入战略与国内机会

从哪里切进去：把一根针磨尖，扎穿一个场景

最忌讳「做一个大而全的 AI 服务平台」。正确姿势是垂直优先、单点撕开、先深后宽。

垂直优先

锁定细分行业 + 细分职能（如「跨境电商的售后客服工单」），而非通用 AI 平台。垂直越窄，数据越集中、结果越可定义、know-how 越能沉淀。

单点撕开

在选定垂直里找一个高频、高痛、可验收的单点任务作楔子，先把「自主解决率能算过账」做到位。

先深后宽

单点站稳后，沿客户工作流向相邻环节扩展，把浅接入变成深嵌入——这正是抗侵蚀壁垒的来源。

国内机会点

传统产业重人力环节（矿山 / 物流 / 质检） 买不起人的中小企业（跨境客服 / 财税） 政企合规刚需（金融风控 / 政务 / 医疗辅助） RPA / 垂直 SaaS 存量客户升级

国内特色：对「纯软件订阅」付费意愿弱，但对「包结果、省人、按效果付」接受度高。难点在数据合规与回款周期。

Make or Buy：买发动机，自己造车担责

环节建议
底层大模型借力（调通用 API）
垂直 workflow / know-how自建（壁垒所在）
交付 / 兜底体系自建（责任无法外包）
合规资质 / 审计自建或合规采买
02 从 0 到 1 可行性路径

选定单点后，怎么一步步跑通

纪律：每一级的门票是上一级的指标达标。越级扩张是从 0 到 1 阶段最常见的死法。

冷启动：点火数据飞轮

找 1–3 个灯塔客户，用「高触碰、几乎贴身服务」先把结果做出来——哪怕早期靠大量人工兜底、不赚钱。把每一次兜底与纠正沉淀成「什么情况下怎么做才成功」的专有过程数据，自主解决率随之爬坡。

早期不追毛利，追「过程数据 → 自主解决率提升」的正循环。

定价落地：把「按结果」写进合同

定义成功：白纸黑字写清什么算「解决」（如工单闭环且 24h 内未重开），避免扯皮。
计费结构：按成功解决量 / 按替代的人 / 里程碑付费 + 结果分成；早期建议混合计费（小额固定 + 结果浮动）平衡现金流。
失败条款：未达结果不收费或降价——签单的信任杠杆。

交付体系：人机协同 + 兜底 + workflow 工程化

三支柱：人机协同（明确哪些置信度以下必须转人工）、兜底机制（阈值 + 异常检测 + 回滚 + 人工接管）、workflow 工程化（编码成可复用流程，区别于「AI 外包作坊」的规模化根基）。

03 关键风险控制清单

哪些坑会致命，怎么防

结果责任在你，风险控制就是活下去的护栏。分技术 / 商业 / 法律 / 组织四类。

技技术风险

幻觉 / 出错（连 Harvey 仍存在幻觉率）：置信度阈值 + 多模型校验 + 监督者模型 + 人工复核 + 可追溯日志。
推理成本波动：模型路由、缓存、蒸馏、成本看板告警。底线是永远保留人工兜底通道。

商商业风险

UE 长期为负（最隐蔽的死法）：坚持保守假设下单次毛利为正才规模化。
客户过度集中：设单一客户收入占比上限。
增长陷阱：以指标达标为扩张门票，而非融资节奏。

法法律风险

担责主体：合同明确责任边界与赔付上限、买责任险、保留人工签字。
合规资质：强监管行业合规前置，无资质别碰高危区。
数据安全：脱敏、隔离部署、明确授权。

组组织风险

人机协同失衡：人力兜底降不下来就退化成外包作坊——把自主解决率作核心 OKR。
人才结构：与领域专家深度绑定/合伙。
被巨头碾压：抢在被碾压前把工作流嵌入与合规壁垒挖深。

红线信号：幻觉致重大赔付 / 推理成本吞掉毛利 / 靠补贴掩盖亏损 / 单客户占比过半 / 无资质碰高危区 / 人工兜底比例长期降不下来。合规与担责能力是入场门票，不是可选项——它既是风险，也是抗侵蚀壁垒。

04 切入决策蓝图

把三主题串成一张从判断到落地的决策地图

选对赛道 → 单点撕开 → 高触碰点火飞轮 → 把概率做成确定性 → 按结果计费 → 指标达标才逐级扩张，不达标就止损。

行动决策树：该进 / 该验 / 该撤

创业者

垂直优先、单点撕开、先深后宽，入场即定止损线，用指标而非情绪做扩张/撤退决策。

投资人

重点看自主解决率趋势、保守 UE、壁垒是否随模型进步贬值，而非只看 ARR 增速。

转型企业

从存量流程/客户切入，最大阻力在内部利益冲突，先解决组织激励再谈技术。

05 退出机制与里程碑

诚实地预设「什么时候该撤」

会切入的人很多，敢在数据不对时止损撤退的人才活得久。止损线要在入场前就白纸黑字定好。

PMF 失败的三条退出信号（触发即认真评估撤退/转型）

连续 3 月无付费还没找到愿为结果买单的真痛点。
流失率 > 30%交付质量 / 自主解决率不达标，结果留不住客户。
交付成本 > 客单价UE 结构性为负，靠补贴续命越做越亏。

战略转型不止「关门」一条路：降维（L3/L4 退回 L1/L2 先做能赚钱的提效工具）、转场景（同套能力迁到结果更可定义的场景）、转模式（从按结果退回高触碰服务/订阅，先活下来）。

里程碑节点

6 个月
  • 至少 1 个灯塔客户付费
  • 单点自主解决率跑到可算过账水平
  • 未达标 → 检修单点或止损
12 个月
  • UE 在保守假设下转正
  • 客户数与留存达标，降低单客户集中度
  • 未达标 → 启动战略转型或退出

止损纪律：把三条止损线绑定客观指标、写在入场前，避免「再坚持一下」的沉没成本陷阱。撤退不是失败，把资源留给下一个更对的赛道才是理性。
